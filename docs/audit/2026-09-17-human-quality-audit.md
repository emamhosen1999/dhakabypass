# Human-quality audit: dhakabypass.com

17 September 2026 · branch `chore/2026-09-06-cutover-and-audit` @ b1d0b04 · local DB `dhakabypass` plus production fetches.
This is a report only. No product files were changed.

## Summary

1. **Overall: 60/100.** Copy (English) 62 · Translation (Bangla/Chinese) 48 · Design 72 · Code 58 · Docs 55.
2. Most of the English on the site reads like careful civic writing. Three things make it read as generated or unedited. Brochure blocks carried over from the old site ("world-class", "transformative", "+85% industrial land value") sit next to plain statements. The site contradicts itself: the home page says project figures are not republished until verified, and the About page publishes them. And nine page openers follow the same "A road of this length… This page is where…" pattern.
3. The biggest trust risks don't come from style. A sample emergency number (+880 2 5555 0199) is live in the footer and in the structured data. 69 relative content links return 404 on nested pages. The privacy notice names TomTom, but the code uses Google Routes. The accessibility statement says Chinese has no font, but one is self-hosted.
4. Bangla and Chinese were written by a model and have not been reviewed (`lib/i18n/ui.js:30-33` says so). You can see it in the Latin place and brand names (the site's own `seo.site_title` uses the local forms), inconsistent terms and spelling, calques, and one invented claim in Bangla. At the owner's request, Bangla is also held to everyday usage (ম্যাপ, আপডেট, লাইভ), and the full substitution table is below.
5. The code avoids the obvious tells: no narrated comments, no emoji, no code blocks copied more than 15 lines. It has the opposite tell: essay-length comments (25% of all lines) full of audit IDs, "deliberately" (90), history notes ("This comment used to say…") and repeated prose. It also has 12 exports nothing uses, 26 functions over 120 lines, and commit subjects averaging 104 characters.

## What already reads as human

- **Plain, specific English on the pages road users rely on.** Rules of the road (page 300) cites the *Motor Vehicle Speed Limit Guideline 2024* and the *Road Transport Act 2018*, gives a speed table by vehicle and carriageway, and says "Tell the operator the nearest kilometre marker (the small posts reading K3, K4 …)". Careers (9034) says: "never recruits through agents or mobile-money payments". Integrity (9037) gives the Anti-Corruption Commission hotline, 106. Land acquisition (161) names the Deputy Commissioners of Gazipur, Narayanganj and Narsingdi and tells people to "take the acquisition notice and the plot number". A generator wouldn't know to write those.
- **It says what's missing.** The accessibility statement says "It is **partially compliant**" and lists its known problems. The procurement page says "No tender notices are currently listed on this website." Placeholder records are labelled "Sample" rather than passed off as real.
- **None of the usual AI vocabulary.** Across all published English block strings: delve 0, seamless 0, robust 0, leverage 0, empower 0, elevate 0, streamline 0, cutting-edge 0, state-of-the-art 0, "in today's" 0, "whether you're" 0, exclamation marks 0. The few hits (world-class, transformative, fostering, innovative, optimal, superior, significantly, ensures) all sit in the legacy blocks (ids 404–412) covered in C4. The one "not only" (sustainability 149) reads naturally.
- **The design has a clear idea behind it.** Pages are built like road signs: a dark blue plate with the logo's orange as the accent. Each colour decision is backed by a measured contrast ratio (`app/design-tokens.css:24-66`). Type is Barlow Semi Condensed with Archivo rather than a default pairing, and Hind Siliguri for Bangla (chosen by the client). There are no emoji, no decorative 01/02/03 numbering (grep found none), no gradient hero (the only gradients are a photo scrim and edge masks), and only 5 `text-align:center` rules.
- **Code:** no narrated-obvious comments (grep for `// Set|Get|Return|Loop|Increment…` found 2 hits, both justified). No code block over 15 lines is copied between files. Names are mostly specific (`publishedLengthKm`, `recordCameraHealth`).
- **Translation mechanics that already work:** Chinese uses full-width punctuation (430 `，` against 7 ASCII commas) and addresses the reader as 您 every time (65 against 0 你). Bangla body copy uses Bengali digits (781 against 401 ASCII, and most of the ASCII is dates, file sizes and standards names).
